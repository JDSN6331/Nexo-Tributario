# Nexo Tributário - Diretrizes do Projeto

Este repositório contém a aplicação **Nexo Tributário**, construída com TanStack Start, React 19, TypeScript e Tailwind CSS.

## Diretrizes de Desenvolvimento
- Manter compatibilidade com SSR e client components do TanStack Router.
- Preservar integridade dos catálogos de produtos e bases normativas da LC 214/2025.
- Manter o padrão visual escuro moderno (Glassmorphism & Aurora Glow) e tipografia Space Grotesk / Inter.
